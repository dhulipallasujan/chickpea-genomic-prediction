
# Raw data

Raw files are not stored in this repository. The pipeline downloads them
from the ICRISAT CicerSeq portal on the first run:
https://cegresources.icrisat.org/cicerseq/?page_id=3444

Files used: 3000_Phenotyping_data_QC.xlsx (sheets ICRISAT_2014-15 and
ICRISAT_2015-16) and the cultivated-panel HapMap chromosome files.
